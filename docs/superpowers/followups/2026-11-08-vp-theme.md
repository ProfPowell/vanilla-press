# Step 4 (themes): rulings and follow-ups

Spec: `docs/superpowers/specs/2026-11-08-vp-theme-design.md`. Plan:
`docs/superpowers/plans/2026-11-08-vp-theme.md` (its R1–R17 rulings stand
except where amended below).

## Rulings made while building

Each has its cost if it's wrong.

- **First token is the brand:** on a page with `data-theme-source="site"`, VB takes the first `data-theme` id as the
  brand, and `default` is valid. Cook, the editor and the live check all write
  the name first: `data-theme="default vp-site"`. *Cost:* one ordering rule
  in three places.
- **Leaving `vp.json` alone:** migration doesn't edit `config/vp.json`. The commit that first adds
  `config/theme.json` removes the old `theme` key. *Cost:* a stale key until
  the first Apply or Publish.
- **Library changes commit at once:** saving, importing, renaming or deleting a custom theme commits and
  pushes at once, like a backup, but never changes the applied look. This amends R2/R3. *Cost:* a deploy build with identical output.
- **Deleting a theme the live site uses:** deleting a custom theme is refused while committed HEAD uses it
  (theme.json or a committed page), and fails closed if git can't be read.
- **Two computers:** when another computer changed the theme, GitHub's version wins, and
  Apply says so. Multi-computer edge cases are otherwise deferred: Vanilla
  Press is single-user for now.
- **New database columns:** the store gained `theme` and `theme_scope` columns. Without them, saves
  dropped a post's theme.
- **Unsafe tokens:** unsafe tokens in a saved theme are skipped and listed, not refused.
- **Composer import:** it also accepts VB's dark form, `:root:not([data-mode=light])`,
  inside a dark `@media` block.
- **Preview:** the Theme screen preview runs in a sandboxed iframe (no scripts).
- **Editor colors:** the editor pane recomputes the main color on `.editor-pane` and
  `.editor-content` until the site's VB has the scoped-tokens fix. Remove it
  then.
- **Theme Composer is 422-only:** an unknown theme on a site with no VB copy gets one build, then a 422.
- **VB scoped themes (beyond the spec):** derived color, font, radius, shadow, glass
  and border tokens are re-declared on `:where([data-theme])`, and theme content
  rules also match a themed `<main>` or `<article>`. A theme applied to `<html>`
  computes exactly as before.
- **VB icons font:** the icons pack loads Material Symbols from Google Fonts
  (the user's choice). A test checks that every `url()` in the built CSS points
  to a shipped file.

## Deferred

- **Two computers:** git can merge `theme.json` line by line, mixing two
  applied looks. `vp-site.css` isn't part of the applied unit. The local dist is
  built with the local theme even when GitHub's wins. A custom theme can be
  deleted here while another computer applied it.
- **Nested themes (VB):** the site theme's content rules still reach into an
  article with its own theme. For example, a swiss h1 is uppercase inside an
  editorial article. Fixing that needs `@scope`-style limits in every theme.
- **Theme behavior:**
  - Line-height doesn't follow a scoped theme.
  - Theme durations override reduced motion inside a scoped element.
  - Custom and imported theme dark rules ignore a parent's `data-mode`.
  - A theme saved from a showcase theme keeps its tokens only, not its web
    fonts or decorations (R10). For example, Press Start 2P isn't loaded.
  - 8bit draws list markers on their own line when an `<li>` holds a `<p>`, at
    any scope.
- **Editor:**
  - Page-scope showcase decorations that need a `main`/`article` descendant may
    still differ in the pane.
  - There's no cache-bust for `vp-site.css` in an open editor tab.
  - A failed `GET /theme` isn't retried.
  - `vp serve` can't clear a post's theme.
  - Appearance's "All themes" state carries over between posts.
- **Theme screen:**
  - The live poll can start off-screen if you leave during Apply.
  - The preview srcdoc could carry a CSP meta.
- **Cook:** fragment (SPA) navigation doesn't load a page's own theme;
  documented.
- **Other:**
  - `frontMatterValue` misses a front matter block without a trailing newline,
    a BOM, or a trailing YAML comment.
  - VB 0.6.0 drops the color-only theme files (amber and others). A site or post
    naming one now shows a notice.
