Do It Yourself Blogging

These days you hear lots of opinions on if vibe coding is real coding or not. In the traditional sense of coding, no vibe coding is not real coding. You didn't open up an editor and type and slowly work with your code to get something out. It isn't coding if that is your definition, but is coding really the issue?

Coding is in a way like writing. Just like I am writing this post word by word sentence by sentence in an attempt to make a coherent point, coding was you as a developer writing each variable, function, and class one by one trying to assemble a whole coherent piece of software. Obviously be it a post or be it a program I could just go ask my friend Claude to do it for me.

"Hey Claude write an introductory post about in simple markdown for my personal blog"

So away we go! Here's Claude's attempt

Who I Am

I'm Thomas Powell. I teach computer science, including software engineering at UC San Diego, and I've spent my career moving back and forth between the classroom and industry.

A quick tour of where I've been:

  • CERFnet, one of the first Internet Service Providers, where I got my start.
  • PINT, Inc., the company I've run since 1995, building websites for corporations.
  • Port80 Software, where we built performance and security products for the Microsoft web ecosystem.
  • ZingSoft, home of ZingChart and ZingGrid, plus a growing family of web-platform-first projects.

Along the way I've also written a number of books on web development.
