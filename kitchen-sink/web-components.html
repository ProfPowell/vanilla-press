What is Vanilla Breeze?

Vanilla Breeze is a CSS design system built entirely on web standards. It uses CSS custom properties for theming, @layer for cascade control, and custom elements as semantic style hooks.

Do I need a build step?

No. Vanilla Breeze uses native CSS features like @import and @layer. Browsers handle everything directly. No Sass, no PostCSS, no bundler required.

How does theming work?

Themes override CSS custom properties on any element with a data-theme attribute. You can theme the entire page or individual sections independently.

Is it accessible?

Yes. The accordion uses native <details>/<summary> elements, which have built-in keyboard support and ARIA semantics. The JS enhancement adds arrow key navigation between sections.

<tabs-wc>

Tabbed interface using the CSS-only radio button pattern. Works without JavaScript; JS can add keyboard arrow-key navigation and dynamic tab management.

HTML provides the structural foundation. Every component in Vanilla Breeze starts as semantic HTML, which means it works even if CSS fails to load.

<article>
  <h2>My Post</h2>
  <p>Content goes here.</p>
</article>

CSS layers manage the cascade. The reset layer comes first, followed by tokens, base styles, layout, and finally components.

@layer reset, tokens, base, layout, components;

JavaScript is optional and additive. It enhances components with features like copy buttons, keyboard navigation, and dynamic content loading.

// Progressive enhancement only
for (const block of document.querySelectorAll('code-block')) {
  addCopyButton(block);
}
