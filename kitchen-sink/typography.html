Definition List

Block AST
A JSON array of typed blocks that represent document content. Each block has a type, optional attributes, and children or a leaf value.
Rendering Scope
One of five output modes: page, content, block, collection, or meta. The scope determines how much of the document is rendered.
Content Negotiation
The server reads Accept headers to determine the response format. The same URL serves HTML, markdown, or JSON depending on the client.

Float Start

When a figure floats to the start, text wraps around it on the end side. This is useful for small images or diagrams that accompany a paragraph of text. The content should be long enough to demonstrate the wrapping behavior properly, so here is some additional context about how CSS floats interact with the normal document flow. Floats were one of the original layout mechanisms on the web, predating flexbox and grid by many years. They remain useful for this specific pattern of text wrapping around a media element.

Float End

When a figure floats to the end, text wraps around it on the start side. This is the more traditional magazine-style layout where images appear in the right margin. Again, the paragraph needs to be long enough to show the wrapping effect. In a content management system, you might allow authors to choose float direction through a block attribute, which the renderer would then convert to the appropriate CSS class. This keeps the content model clean while providing layout flexibility.
