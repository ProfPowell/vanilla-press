# Step 3b (Media): rulings and follow-ups

Spec: `docs/superpowers/specs/2026-11-03-vp-media-design.md`. Plan:
`docs/superpowers/plans/2026-11-07-vp-media.md` (its M1–M15 rulings stand
as written there).

## Rulings made while building

Each has its cost if it's wrong.

- **PM1:** PDF gets a palette entry like Image, Audio and Video. *Cost:* one
  extra palette row.
- **PM2:** the featured image on thomasapowell.com uses a site-local Cook
  plugin (`plugins/featured-image.js`), not new layout conditionals in Cook.
  *Cost:* a 20-line plugin to replace if Cook gains conditionals.
- **PM3:** `og:image` alone, no other Open Graph tags. *Cost:* add them later.
- **PM4:** Publish and Update refuse a post that uses a file missing from
  `src/media` (M13). *Cost:* such a post can't go live until it's fixed.
- **PM5:** the site change is a local commit (thomasapowell.com `c3bc35a`)
  touching only its three files, not pushed.
- **Task 4:** no `Connection: close` on an oversize upload's 413. With it,
  browsers showed a network error instead of the size message. *Cost:* the
  socket idles about 5 s.
- **Task 11:** the missing-file block runs in the app only. `vp serve`
  publishing is a plain save. *Cost:* `vp serve` can publish a post with a
  missing file.
- **Final review:** a file counts as used if any page committed in git HEAD
  under `src/` shows it, as well as by saved post bodies. This covers a
  published post edited but not yet Updated, and hand-written pages. Media
  URLs encode the file name.

## Deferred minor issues

- **File inspection:**
  - The AVIF size reader scans the whole file for `ispe`.
  - `formatBytes` shows "1024 KB" just under 1 MB.
  - The MP3 sniff doesn't reject the reserved version bits.
  - A name like "Notes v1.2" loses its "2" from the slug.
- **Library sync:**
  - If VP restarts after adopting stray files but before the backup fires,
    `media.json` stays modified and blocks pull-on-open. Posts have the
    same gap.
  - Adoption reads whole files to sniff them.
- **Server:**
  - The usage map loads each document separately.
  - The first live-page scan runs one `git cat-file` per page; use `--batch`
    if sites grow large.
  - A `rev-parse` failure counts as "no HEAD", so DELETE skips the live
    check.
  - A committed HTML page over 16 MB makes every DELETE return 503.
  - Range edge cases: `a>b` gets 416 instead of 200, and a zero-byte file
    with a suffix range gets a 206.
- **Media screen:**
  - A few raw radii (10px, 6px) and a 1.5px border.
  - The drag highlight can stick after a drag leaves the window.
  - axe reports a moderate issue for the `<aside>` inside the `<section>`.
    The mockup places it there.
  - `media-page.js` is about 550 lines; split the detail panel out.
  - After a refused delete, the message doesn't name the posts or pages, and
    the tile isn't refreshed.
  - Near the limit, the size message reads "25.0 MB … over 25 MB".
- **Editor:**
  - Only figures show "Missing file". Audio, video and PDF blocks don't,
    though Publish still refuses.
  - The drop queue keeps finished entries.
  - Turning on the PDF viewer in Components was simulated in the browser
    check, not clicked.
  - Old references to odd adopted names (e.g. `/media/a#1.jpg`, stored before
    the encoding fix) are still misread. There's no migration.
- **Docs:** the README's Delete bullet is long.
- **Still open from 3a:** the tab-rename `prompt()` and the `alert()` when a
  post fails to load in `vp serve`.
